# Authorized local data files

The repository intentionally does not distribute animal-level source data. To reproduce the analyses, place authorized local copies of the following files in this directory:

- `NIBP_IBP_event_dataset_v3_registry_weight.csv`
- `WP7_event_covariates_for_reproduction.csv`
- `WP10_session_level_dataset.csv`

The underlying records are corporate records of Boston Scientific Japan K.K.; external release requires company approval.
